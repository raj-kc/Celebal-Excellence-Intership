# 🚀 Celebal Technologies – Data Engineering Excellence Internship (8 Weeks)

> A complete collection of assignments, mini-projects, notebooks, and learning resources completed during the **Celebal Technologies Excellence Internship Program (Data Engineering Track)**.

---

## 📌 About

This repository contains everything I completed throughout the **8-week Celebal Technologies Excellence Internship**.

The internship focused on building strong fundamentals of modern **Data Engineering** using industry-standard technologies including:

- Python
- SQL
- Apache Spark (PySpark)
- Databricks
- Delta Lake
- Data Warehousing
- ETL Pipelines
- Data Cleaning
- Analytics
- Azure Data Engineering Concepts

Throughout the internship, I completed weekly assignments, hands-on labs, and an end-to-end data engineering project that simulates real-world workflows.

---
# 🎯 Internship Objectives

- Understand modern Data Engineering architecture
- Learn distributed data processing using Apache Spark
- Build scalable ETL pipelines
- Work with Delta Lake tables
- Perform incremental data processing
- Write optimized SQL queries
- Build analytical reports
- Practice industry best practices for data cleaning and transformation
- Gain hands-on experience with Databricks
